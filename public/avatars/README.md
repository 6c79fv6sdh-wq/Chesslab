# Аватары соперников

Сюда кладутся картинки ботов из «Спарринга». Больше ничего делать не
нужно: код уже ссылается на эти пути, файл подхватывается сам.

## Требования к файлу

- **Формат:** WebP (тот же, что у `public/showcase/*.webp`).
- **Пропорции:** квадрат.
- **Размер:** от 256×256. Больше 512×512 смысла нет — кружок в интерфейсе
  58 px, лишние пиксели только утяжелят офлайн-кэш.
- **Кадр:** лицо/морда крупно и по центру. Кружок мелкий, широкий план
  в нём не читается.
- **Вес:** ориентир ~8–16 КБ, как у скриншотов витрины. Все десять
  попадают в precache сервис-воркера, поэтому лишний вес — это лишние
  мегабайты у каждого ученика.

## Имена файлов

Слаг берётся из поля `avatar` в `src/core/bots.ts`. Это НЕ `id` бота:
`id` заморожен, потому что лежит в каждой сохранённой партии и по нему
восстанавливается соперник при доигрывании.

## Пока файла нет

Ничего не ломается: `<img>` молча снимает себя по `onerror`, и остаётся
кружок-заглушка с первой буквой имени. Так что аватары можно завозить
по одному, а не все десять разом.
