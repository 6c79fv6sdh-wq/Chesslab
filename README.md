# ScienceChess HyperLab

Локальный тренажёр моторики и скорости для ultrabullet. Работает целиком в браузере,
без сервера, аккаунтов и внешних запросов. Все данные лежат в IndexedDB на устройстве.

С Lichess во время игры тренажёр не взаимодействует и вводить ходы за вас не умеет.

## Стек

- TypeScript, Vite
- [Chessground](https://github.com/lichess-org/chessground) — доска Lichess, набор фигур cburnett
- [chessops](https://github.com/niklasf/chessops) — легальность ходов и разбор позиций
- [idb](https://github.com/jakearchibald/idb) — обёртка над IndexedDB
- Vitest — тесты

## Запуск в Codespaces

Всё запускается одной строкой в терминале, десктоп не нужен.

```bash
npm install
```

Разработка с горячей перезагрузкой:

```bash
npm run dev
```

Тесты:

```bash
npm test
```

Продакшн-сборка (в неё входит service worker, без него не будет offline):

```bash
npm run build
```

Просмотр собранной версии:

```bash
npm run preview
```

## Как открыть на iPad

1. Запусти `npm run preview` (именно сборку: в режиме `npm run dev` service worker выключен).
2. В Codespaces открой панель **Ports**, найди порт `4173`, поставь видимость **Public**
   и скопируй адрес.
3. Открой этот адрес в Safari на iPad.

Порт можно открыть и командой:

```bash
gh codespace ports visibility 4173:public -c $CODESPACE_NAME
```

Для работы совсем без сети сборку надо один раз открыть при интернете: service worker
скачает всё в кеш, после этого приложение открывается offline.

## Установка PWA на Home Screen

1. Открой адрес сборки в **Safari** (в других браузерах на iOS установки нет).
2. Кнопка **Поделиться** внизу экрана.
3. **На экран «Домой»**.
4. Имя по умолчанию — HyperLab. Нажми **Добавить**.

Приложение запустится в отдельном окне без адресной строки. Данные IndexedDB
у установленного приложения общие с Safari по тому же адресу.

## Публикация в интернет (чтобы открывалось у других людей)

Тренажёр — статический сайт, поэтому его раздаёт бесплатный GitHub Pages.
Сервера и платного хостинга по-прежнему нет.

Собранный сайт уже лежит в ветке `gh-pages`. Осталось два переключателя
в веб-интерфейсе GitHub, их может сделать только владелец аккаунта:

1. **Settings → General → Danger Zone → Change visibility → Public.**
   Бесплатный Pages работает только на публичном репозитории. После этого
   код виден всем — это плата за бесплатный хостинг.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch →
   Branch: `gh-pages`, папка `/(root)` → Save.**

Через минуту-две сайт поднимется. Дальше он обновляется сам: workflow
`.github/workflows/pages.yml` на каждый push в `main` прогоняет тесты,
собирает и перезаписывает ветку `gh-pages`. Если тесты падают, публикации не будет.

Адрес получится такой:

```
https://6c79fv6sdh-wq.github.io/Chesslab/
```

Ссылку можно отправлять кому угодно: вход не нужен, работает с любого устройства.
Service worker и установка на Home Screen на этом адресе тоже работают.

Запустить публикацию вручную, не дожидаясь push: вкладка **Actions** →
**Публикация на GitHub Pages** → **Run workflow**.

## Где лежат данные упражнений

| Что | Файл |
| --- | --- |
| Линии дебютных репертуаров, SAN | `src/data/repertoire.ts` |
| Позиции для модуля Premove, FEN | `src/data/premove-positions.ts` |

Оба файла проверяются автотестами: `tests/repertoire.test.ts` проигрывает каждую
линию движком от начальной позиции, `tests/premove-positions.test.ts` проверяет
валидность каждого FEN и легальность ожидаемого, ответного и неожиданного ходов.
Если добавишь линию или позицию с ошибкой, `npm test` это поймает.

Загрузка своего PGN в первой версии не предусмотрена.

## Вкладки

1. **Калибровка** — размер доски, способ ввода, координаты, профиль устройства,
   метка настроек указателя. Эти значения пишутся в каждый замер всех модулей.
2. **Моторика** — 30 повторов source-target с телеметрией указателя.
3. **Premove** — форсированное взятие, safe/unsafe, отмена.
4. **Реакция** — бесплатное взятие, безопасный шах, дельта позиции; экспозиция
   без лимита / 500 / 300 / 200 мс.
5. **Дебюты** — три репертуара, задержка ответа на каждом узле, заминки.
6. **Скрэмбл** — партии 15/10/5 секунд против четырёх профилей бота.
7. **Данные** — сводные таблицы, экспорт и импорт JSON, очистка измерений.

## Хранение, экспорт и импорт

Всё лежит в IndexedDB `sciencechess-hyperlab`: настройки калибровки, сессии,
замеры и статистика дебютных узлов.

На вкладке **Данные**:

- **Экспорт в поле** — JSON в текстовое поле,
- **Скачать файл** — тот же JSON файлом,
- **Импорт из поля** и **Импорт из файла** — обратная загрузка (слияние по id),
- **Очистить измерения** — удаляет сессии, замеры и статистику узлов,
  настройки калибровки при этом остаются.

Синхронизации между устройствами нет и не планируется: перенос только через экспорт.
